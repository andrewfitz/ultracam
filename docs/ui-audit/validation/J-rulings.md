# J · Rulings on audits G, H and I

Date: 2026-10-31. Every finding in G, H and I is applied unless a line below changes it. Where they conflict, this file decides, and README follows it.

## Owner decisions that stand

Monitor tools collapse at rest with enabled tools showing, and expand on hover. Switching lives in the toolbar. Settings uses tabs. No output mode. Format is in the main UI. Channels Shown is in Settings › Audio. Not reopened by any finding.
