## Sony Camera Remote SDK

`Vendors/Sony/SDK/README.md` documents the local, Git-ignored SDK
installation, relocated from `ThirdParty/SonyCameraRemoteSDK/`. The vendor
manifest identifies SDK version 2.2.0.
The app embeds the installed Sony runtime libraries, including `CrAdapter`,
when the SDK is enabled; the camera extension must not embed them.

The inspected local installation contains `libCr_Core.dylib`,
`libmonitor_protocol.dylib`, `libmonitor_protocol_pf.dylib`, and the adapter
libraries `libCr_PTP_IP.dylib`, `libCr_PTP_USB.dylib`, `libusb-1.0.0.dylib`
and `libssh2.dylib`. This is an observed inventory, not a fixed list for all
SDK versions. Sony's archive may include additional third-party obligations;
filenames alone do not establish versions or license terms.

**Official release gate: missing redistribution evidence.** No Sony runtime
license/EULA or SDK third-party notice file was found in the inspected SDK
installation. Apache-2.0 does not grant rights to these libraries. Before an
official release, record the exact SDK version, archive identity, applicable
terms and permission to redistribute every embedded runtime component,
including required notices for libusb, libssh2 and any other bundled dependency.
See [SDK release evidence](docs/SDK_RELEASE_EVIDENCE.md). Local SDK availability,
successful signing or a successful build does not satisfy this gate.
